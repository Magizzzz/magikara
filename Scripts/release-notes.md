## 下载

下载下面的 **`MaGi-Kara-0.1.0.dmg`**，打开后把 MaGi Kara 拖进「应用程序」。

> 需要 Apple 芯片（M1 及以后）的 Mac，macOS 14 或更新。

## 第一次打开（只需一次）

作者没有付费买 Apple 签名，第一次打开会被系统拦下，不是病毒：

1. 双击打开 → 弹窗点「完成」
2. **系统设置 → 隐私与安全性**，拉到最下面点 **「仍要打开」**，输入开机密码

如果提示「已损坏，无法打开」，在「终端」里运行这一行再打开：

```bash
sudo xattr -dr com.apple.quarantine "/Applications/MaGi Kara.app"
```

## 一键配置 AI 模型

打开后会弹出 **「运行环境配置单」**：勾选许可 → 点 **「一键安装」**。

- 约 1.5 GB，一般 3–15 分钟；国内网络会自动走国内镜像
- 断网 / 取消都没关系，下次接着下
- 之后也可以在菜单栏 **MaGi Kara → 运行环境配置单…** 打开

## 用法

导入 MV / 歌曲 → 粘贴日语歌词（或「在线搜歌词」）→ **生成 AI 歌词** → 时间线微调 → **导出** MP4。
