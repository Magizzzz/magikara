MaGi Kara 安装说明
==================

适用：Apple 芯片（M1 / M2 / M3 / M4 …）的 Mac，macOS 14 或更新。
（Intel 芯片的 Mac 不支持：对轨用的 PyTorch 已不再提供 Intel Mac 版本。）

1. 把左边的「MaGi Kara」拖进「Applications（应用程序）」文件夹。

2. 第一次打开会提示「无法验证开发者」或「已损坏」——这是因为作者没有付费购买
   Apple 开发者签名，不是病毒。按下面任意一种方法放行（只需要做一次）：

   方法 A（推荐）：
     双击打开一次 → 弹窗点「完成」/「取消」
     → 打开「系统设置 → 隐私与安全性」，拉到最下面
     → 看到「已阻止 MaGi Kara」，点「仍要打开」，输入开机密码
     → 再点一次「打开」。

   方法 B（提示「已损坏，无法打开」时用这个）：
     打开「终端」，粘贴下面这一行，回车，输入开机密码（输入时不显示，正常）：

       sudo xattr -dr com.apple.quarantine "/Applications/MaGi Kara.app"

     然后正常双击打开。

3. 第一次打开会弹出「运行环境配置单」，点「一键安装」：
   - 会下载约 1.5 GB（人声分离模型、对轨环境、日语歌唱对轨模型），
     一般 3–15 分钟，国内网络会自动走国内镜像；
   - 中途断网或取消都没关系，下次接着下；
   - 不想现在装可以点「稍后再说」，之后在菜单栏「MaGi Kara → 运行环境配置单…」里随时打开。

4. 用法：导入 MV 或歌曲 → 粘贴日语歌词（或在线搜索）→ 点「生成 AI 歌词」→ 导出 MP4。

说明：
- 日语歌唱对轨模型（Yohane）采用 CC BY-NC-SA 4.0 许可，只能个人非商业使用。
- 所有组件装在「~/Library/Application Support/MaGiKara」和「~/Library/Caches/MaGiKara」，删掉这两个文件夹即可完全卸载。
